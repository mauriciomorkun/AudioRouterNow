🔀

Every output at once

Speakers, headphones, your studio interface — all playing together. And your volume keys still work, unlike macOS Multi-Output.

🔒

Sandboxed. No driver.

Built on Apple's Process Tap API — no HAL plugin, no kernel extension, no admin password. One click in the App Store, done.

⚡

One click. It remembers.

Pick outputs from the menu bar. Plug in a device, it shows up instantly. Reboot — your setup is still there.

✂️

Not a mixer. No restart.

No mixer, no routing diagram, no per-app rules. Pick your outputs, click once, done — no restart, no setup wizard.

AudioRouterNow 4 — in action

Want to mix sources, add effects, or route per app? Get Loopback or Audio Hijack. AudioRouterNow does one thing: one source, every selected output.
