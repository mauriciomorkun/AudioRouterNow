# AudioRouterNow v3 (Legacy — Python/HAL)

> ⚠️ **This version is no longer actively developed.**
> The current version is [AudioRouterNow 4 (Swift, App Store)](../v4/).

## What is v3?

AudioRouterNow v3 is the original Python/HAL-plugin implementation.
It runs without the App Store and without Swift — directly as a system audio driver.
